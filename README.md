# Teachers Kingdom

**Öğren. Öğret. Üret.** — *You can do it*

Almanca CEFR **A1** ve **A2** dil öğrenme platformu (Vite + React + TypeScript + Tailwind CSS).

## Özellikler
- **5 Temel Beceri (A1 & A2):** Kelime (Wortschatz), Dinleme (Hören), Okuma (Lesen), Yazma (Schreiben), Konuşma (Sprechen)
- **Etkileşimli Etkinlikler (A1 & A2):** Karaoke Stüdyosu, Sessiz Sinema, Arena, Quiz Merkezi, Sınav Bankası
- **Öğretim Araçları:** Sınıflarım, Ödevler, Öğretmen Stüdyosu
- **Yerel İlerleme & Veri Taşınabilirliği:** Tarayıcı `localStorage` kaydı, çift XP korumalı JSON yedekleme/içe aktarma ve TR/EN arayüz desteği

## Geliştirme ve Derleme

```bash
npm install
npm run dev
npm run lint
npm run build
```
